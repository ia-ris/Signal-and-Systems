ABOUT THIS PAGE

This web page shows the graph of the code and visualizes discrete convolution: the input signal, the impulse response, and the resulting output.

It is based on the MATLAB lab assignment in Signal-and-Systems and presents the convolution results in an interactive graphical interface.

CONVOLUTION MODEL

y[n] = Σ x[k]h[n − k]

IMPLEMENTATION

The MATLAB routine myconv.m calculates the output with the built-in conv function and determines the output index range from the two input index vectors.
